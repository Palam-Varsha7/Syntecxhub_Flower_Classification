# Syntecxhub_Flower_Classification
 Iris Dataset

## About
A Machine Learning project that classifies Iris flower species 
(Setosa, Versicolor, Virginica) using classification algorithms.
Built as part of Syntecxhub Internship - Project 1.

## Libraries Used
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## What This Project Does
- Loads the Iris dataset
- Performs EDA and visualizes feature pairs
- Trains Logistic Regression & Decision Tree models
- Compares accuracy of both models
- Plots Confusion Matrix for both models
- Predicts flower species for new user input

## How to Run
1. Install libraries:
pip install pandas numpy scikit-learn matplotlib seaborn
2. Run the script:
python classification.py
3. Enter flower measurements when prompted

- Logistic Regression Accuracy: 100%
- Decision Tree Accuracy: 100%
